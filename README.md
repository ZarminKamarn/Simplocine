# Simplo'ciné

Simplo'ciné est un site web responsive réalisé dans le cadre d’un brief en formation.
Il permet à ces utilisateurs de consulter et découvrir des films et séries.

## Installation

### Cloner le dépôt

```bash
git clone git@github.com:ZarminKamarn/simplocine.git
cd simplocine
```

### Installer les dépendances

```bash
npm install
```

### Lancer le projet

```bash
npm run dev
```

Le projet se lance sur le port 5173.

## Site Internet

Vous pouvez retrouver le site déployé sur https://emilie-simplocine.vercel.app/.
